# eCommerce Shop

A simple eCommerce website built with HTML, PHP, and Bootstrap.

## Features

- Product listing
- Product details
- Shopping cart
- Checkout process

## Setup

1. Ensure you have PHP installed.
2. Run the built-in PHP server: `php -S localhost:8000`
3. Open `http://localhost:8000` in your browser.

## Structure

- `index.php`: Home page
- `products.php`: Product listing
- `product.php`: Single product page
- `cart.php`: Shopping cart
- `checkout.php`: Checkout form
- `includes/`: Common includes (header, footer, functions)
- `css/`: Custom styles
- `js/`: Custom scripts
- `images/`: Product images
